03 / 07

Instant Session Memory in One Keystroke

Bridges raw git history with human working memory in under 10 seconds.

01 • Capture
Zero-Friction Keystroke
Press Cmd+Shift+S. Answer 4 quick prompts in 10s while it automatically captures git branch, modified files, diff stats, active tabs, and commits.
02 • Evaluate
Resume Readiness Score
Transparent 0–100 score based on 6 deterministic rules. No hallucinated AI scores—developers instantly know if their context is complete.
03 • Restore
1-Click Flow Restoration
Click Resume in the Dashboard: it reopens your modified source files in VS Code and highlights the exact next line of code you need to touch.

Technical Architecture
04 / 07

Privacy-First, Zero-Backend Architecture

Engineered to run 100% locally on the developer's machine with zero infrastructure cost.

Local Extension Host
Native VS Code Integration
• Git Service: Native shell-out to git status --porcelain, diff stats, and commit logs.
• Workspace Scanner: Parses active editor tabs, project structure, and pending TODO markers.
• Zero Data Leakage: Automatically ignores .env files, API tokens, and credentials.
• Local Persistence: Stores checkpoints as JSON in VS Code's encrypted global storage.
Hybrid AI & Resilience
Client-Side AI & Offline First
• Gemini 1.5 Flash: Client-side REST call generates concise 3-sentence executive summaries.
• Graceful Degradation: If offline or without an API key, the core product operates 100% offline without crashing.
• React Webview UI: High-performance bundled dashboard with animated SVG score rings and timeline.

Core Innovation
05 / 07

The Resume Readiness Score (0–100)

Deterministic, rule-based scoring that coaches developers to leave clean checkpoints.

Evaluation Check Weight Rule Reason & Purpose
Task Description +25 pts Ensures the core objective is documented so you never return to a blank slate.
Modified Files Tracked +20 pts Git status recorded modified & untracked files for automatic editor reopening.
Last Known Blocker +20 pts Prevents repeating failed debugging attempts when you resume tomorrow.
Next Action Defined +20 pts Provides immediate momentum on return with zero reorientation delay.
Validation Status +10 pts Records whether local builds or unit tests were passing or broken.
Working Branch +5 pts Rewards isolated feature branches over direct commits to main.
