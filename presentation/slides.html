Technical Architecture

Engineered for Privacy, Speed & Zero Costs

No expensive cloud backends. Everything executes locally in the developer's sandboxed environment.

Client-Side Extension Host
• Git Service: Native shell-out to git status, git diff --stat, and commit logs.
• Workspace Scanner: Parses active editor tabs, project structure, and pending TODO/FIXME markers.
• Encrypted Local Storage: Checkpoints are persisted in VS Code's local storage path as JSON.
Hybrid AI & Offline Resilience
• Gemini 1.5 Flash: Client-side REST call for optional 3-sentence executive summaries.
• 100% Offline Mode: If offline or without an API key, the product works completely locally without crashing.
• Zero Data Leakage: Secrets, .env files, and private keys are strictly excluded.
Core Innovation

Resume Readiness Score (0–100)

A rule-based evaluation engine that objectively grades how resume-friendly a session is.

Evaluation Rule Points Why it matters
Task Description +25 pts Ensures clear intent is recorded so you don't return to blank context.
Modified Files Tracked +20 pts Git status captured changed and untracked files for automatic reopening.
Last Known Blocker +20 pts Prevents repeating failed debugging approaches when you return.
Next Step Defined +20 pts Gives you immediate momentum on resumption with zero disorientation.
Validation Status +10 pts Records whether unit tests or local builds were passing or broken.
Feature Branch +5 pts Rewards working on isolated branches rather than committing to main.
